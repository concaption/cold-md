# 2026-04-17 - Initial scaffold

## What shipped

- Repo scaffold (CLAUDE.md, memory/, spec/, examples/, skill/, README, LICENSE, .gitignore).
- `spec/cold-md-v0.md` - first draft of the spec. Eight sections: Identity, Audience, Value, Voice, Proof, Sequence, Objections, Banned. "What a conforming agent does" list. Optional YAML frontmatter with `coldMdVersion`.
- `examples/minimal.cold.md` - starter template.
- `examples/foxreach.cold.md` - reference implementation, also doubles as FoxReach marketing.
- `skill/cold-outreach/SKILL.md` - Claude Code skill that reads a cold.md and drafts per-spec.
- README positions the project, shows quickstart, lists implementations (this skill + FoxReach).
- LICENSE: MIT for code, CC-BY-4.0 for the spec.

## Decisions made

- One file at repo root (`./cold.md`) is the convention. `$COLD_MD` overrides.
- Spec license split from code license to encourage third-party implementations.
- Banned list is a hard filter, not a guideline. Voice rules enforced verbatim. Proof is the only citation source. Silent degradation is a bug.
- Repo name on GitHub: `cold-md` (GH dislikes dots). Domain stays `cold.md`.
